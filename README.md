# Cape Town Load Shedding & Water Alert Tracker

A web application where Cape Town residents can view load shedding and water
status for their area and submit community reports of outages.

**Status:** In development (Phase 2)

## Tech stack
- Front-end: HTML, CSS, JavaScript
- Back-end: Node.js with Express
- Database: SQLite

## Running the project locally

1. Install [Node.js](https://nodejs.org) (LTS version).
2. Clone this repository and open the folder in a terminal.
3. Install dependencies: `npm install`
4. Start the server: `npm start`
5. Open http://localhost:3000 in your browser.

*Full installation and usage instructions will be completed at the end of the project.*
